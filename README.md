# Shop

## Описание
API проекта магазина продуктов.

## Функциональность
- просмотр категорий и подкатегорий
- просмотр списка товаров
- управление категориями и подкатегориями в админке
- добавление товаров в корзину
- изменение количества товаров в корзине
- удаление товаров из корзины
- очистка корзины
---

## Стек технологий
- Python 3.12
- Django 4.2.23
- Django REST Framework 3.17.1
- SQLite

## Локальное развертывание проекта

### 1. Клонировать репозиторий

```bash
git clone https://github.com/ToSky26/Shop.git
cd Shop
```

### 2. Создать виртуальное окружение
```bash
python3 -m venv venv
```

### Активировать виртуальное окружение.
```bash
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Выполнить миграции
```bash
python manage.py migrate
```

### 6. Запустить сервер разработки
```bash
python manage.py runserver
```
После успешного развертывания проект доступен:

Сервер:
[http://127.0.0.1:8000](http://127.0.0.1:8000)

Админка:
[http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
